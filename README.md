# KMP Player

Личный музыкальный плеер: свои треки, онлайн-поиск, микшер с эффектами и пресетами, лента с моментами треков. Устанавливается на телефон как приложение (PWA).

## Выложить на GitHub Pages и пользоваться с телефона

1. Создай репозиторий на github.com, например `kmp-player` (Public).
2. Нажми «uploading an existing file» и перетащи **все файлы из этой папки** (включая `icons`, `supabase`, `.nojekyll`). Нажми «Commit changes».
3. Открой Settings → Pages → Build and deployment: Source «Deploy from a branch», Branch `main`, папка `/ (root)`, затем Save.
4. Через 1–2 минуты сайт будет по адресу `https://ТВОЙ_НИК.github.io/kmp-player/`.
5. На телефоне открой этот адрес:
   - **Android (Chrome):** меню ⋮ → «Установить приложение», или кнопка «Установить приложение» в разделе «Лаборатория».
   - **iPhone (Safari):** «Поделиться» → «На экран Домой».

Обновить приложение: загрузи новые файлы в репозиторий поверх старых. Телефон подтянет обновление при следующем открытии.

## Что работает на GitHub Pages

- Свои треки, плейлисты, микшер, пресеты, умные функции, Лаборатория. Всё хранится в памяти браузера на устройстве.
- Поиск Audius (полные треки) и Apple Music (превью 30 сек) идёт напрямую из браузера.
- Jamendo работает только в локальной версии, потому что ключ нельзя хранить в открытом коде страницы.
- Лента по умолчанию локальная. Чтобы она стала общей для всех, подключи Supabase (ниже).

## Аккаунты, облачная библиотека и общая лента (Supabase, бесплатно)

Что даёт подключение:
- регистрация, вход, сброс пароля, профиль (имя, ник, аватар, «о себе»);
- треки загружаются в облако и появляются на всех устройствах, где ты вошёл; удаление тоже синхронизируется;
- лайки, плейлисты, свои пресеты микшера и счётчики прослушиваний одинаковые везде;
- общая лента: посты с моментами, лайки, комментарии;
- удаление аккаунта вместе со всеми данными.

Настройка (10 минут):
1. Зарегистрируйся на https://supabase.com и создай проект (регион ближе к тебе, например Frankfurt).
2. **SQL Editor → New query**: вставь весь файл `supabase/schema.sql` и нажми **Run**. Скрипт создаёт таблицы, правила доступа, хранилища `tracks` и `avatars`. Его можно запускать повторно.
3. **Project Settings → API**: скопируй **Project URL** и ключ **anon public** в `config.js`.
4. **Authentication → URL Configuration**: в **Site URL** и **Redirect URLs** впиши адрес сайта, например `https://karenosipov.github.io/kmp-player/`.
5. Загрузи обновлённый `config.js` на GitHub (`git add . && git commit -m "supabase" && git push`).
6. Открой KMP, нажми на иконку профиля и зарегистрируйся.

Полезно знать:
- Anon-ключ можно хранить в открытом коде: доступ к данным защищён правилами (RLS). Чужие треки и файлы недоступны. **Ключ service_role никуда не вставляй.**
- Бесплатно: 1 ГБ файлов (примерно 200–250 MP3), до 50 МБ на файл.
- Письма подтверждения на бесплатном тарифе отправляются ограниченно (несколько в час). Если нужно быстро протестировать, отключи **Authentication → Providers → Email → Confirm email**.
- Если выйти из аккаунта, облачные треки убираются с устройства и возвращаются после входа.

## Локальный запуск (с Jamendo)

Нужен Node.js 18+. Зависимостей нет.

```
npm start
```

Открой http://localhost:5173. Для Jamendo скопируй `.env.example` в `.env` и впиши бесплатный ключ с https://devportal.jamendo.com.

## Горячие клавиши

Пробел: пауза. ← →: перемотка. Shift + ← →: предыдущий и следующий трек. F: полный экран. M: микшер. L: лайк. K: сохранить момент. [ и ]: петля A–B, \: сбросить петлю. /: поиск.

## Ограничение на iPhone

Плеер обрабатывает звук через Web Audio, чтобы работали эффекты. На iPhone при блокировке экрана Safari может приостановить звук. На Android и компьютере музыка играет в фоне.
